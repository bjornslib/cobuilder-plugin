5. Why label holdout 2 first the rationale for my recommendation

  • It answers the open question fastest. The holdout showed a gain on CoBuilder work only. A and C need no new training for this test, so the only work is the references and two runs.
  • It spends effort where the answer changes the plan. If C holds up on other projects, training data is less urgent. If it fails, we know that more varied training data is the fix.
  • It keeps a clean before-and-after. We score the current C, which trained on CoBuilder only, on other projects. If we trained on the new data first, we could not tell what C gained.
  • It keeps the test fair. The confirmed references of holdout 2 never go into a prompt, a demo or GEPA.

Limit: agencheck is a different codebase but probably a similar kind of work. Story-writer has 2 and the pre-employment project has 3 holdout sessions, so each of them on its own gives little. The three together, 5 sessions, give a first view.
