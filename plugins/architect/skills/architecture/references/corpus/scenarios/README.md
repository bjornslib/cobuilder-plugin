# Architecture / DDD / Resilience Scenarios

Synthetic scenarios for training on architectural decision-making, domain modeling, resilience patterns, and legacy modernization.

## Subdirectories

- `architecture/` — Architecture decision scenarios (trade-offs, patterns)
- `ddd/` — Domain-Driven Design scenarios (bounded contexts, aggregates)
- `resilience/` — Resilience pattern scenarios (circuit breakers, bulkheads, retries)
- `legacy/` — Legacy code modernization scenarios

## Format

Each file: markdown with `## Scenario`, `## Constraints`, `## Questions`, and `## Model Answer`.
