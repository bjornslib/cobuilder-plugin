Findings and open doubts

  • ADR-0034 stands against a column board in the drawer. It rejected five Kanban columns inside the Work drawer, and its rule says that no full-page board route remains. Each option here needs a full page. So this design must amend ADR-0034, whichever layout wins.
  • Done is most of the data. 127 of 130 joined slices are done, and 51 of 112 epics are done. Each prototype folds Done. A slice-grain board shows little work in flight today.
  • Some slices have no program. The index holds 172 slices. 42 join no epic of a design, because their plans have no design: priority-dev-spike 31, level-page-restructure 5, coach-reaches-green 3, describe-boundaries 3. The prototypes do not show them.
  • An epic has no name in the index. The epic entity holds an id, a branch, and a pull request, and no title. The prototypes show the last part of the branch, so the 19 epics of cobuilder-viewer all read work-prototype. The tracker holds a title for each epic, such as "The exporter seam". A readable card needs build_index.py to put that title in the index.
  • The index holds no date, priority, or assignee. The sort uses the stage, the name, the open work, and the progress only. A sort by date or priority needs a change to build_index.py.
  • The prototypes are read-only. The viewer is a static page, and workflow state moves only through tracker.py. A drag that changes a status needs a write path that does not exist.
  • Unverified. The prototypes are vanilla HTML, not the React viewer. They prove the layout, not the build. Project memory was not reachable in this session, so no memory record was checked.

The decision: which layout does the design take forward?

  1. Which layout wins: A, B, C, or a mix that you name?Recommendation: B for the survey of all programs, with the aligned bands of its dock. Second choice: A, for the smaller build.
  2. Where does the board live: a new full page beside the Work drawer, or in place of the drawer?Recommendation: a new full page, and the drawer stays. ADR-0034 gets an amendment.
  3. Is the board read-only in this design?Recommendation: yes. A status change stays with tracker.py.
  4. Do slices with no program get a lane of their own?Recommendation: yes, one lane named "No program", closed by default.
