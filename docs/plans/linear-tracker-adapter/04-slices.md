# Slices: linear-tracker-adapter

Gate 4a for the whole program. Seven epics, E1 to E7, and 13 slices. The epics follow the build order of ADR-0048. E1 to E5 need no Linear workspace. E6 needs a test workspace, and E7 follows it. Gate 4b and 4c are pending.

Test command for each slice: `uv run pytest tests -q`. Run the full suite once after the whole build. In each slice, run the tests of that slice, as the RED and GREEN roles do.

Rubrics path: `.cobuilder/rubrics/linear-tracker-adapter/`.

## What makes a slice here

Each slice ends in one thing that a test asserts or a reader sees. A slice never says "add the types" or "add the client". Each slice crosses the layers it needs, from the command to the stored state in the fake Linear. E1 slice 1 is the tracer bullet. It proves the seam: the shared contract read cases run on a `linear` adapter over `FakeLinear`.
