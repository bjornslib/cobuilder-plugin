Alternatives considered

1. Monolithic In-Memory Event Bus Rejected: Memory Leaks

Cross-district leakage occurred during complex multi-tab canvas navigation, violating GC isolation requirements.

2. Direct Canvas WebGL Rendering Rejected: Accessibility Loss

Direct GPU rasterization stripped screen reader compatibility from individual structural diagram nodes.

3. Client-Side Polling for AST Updates Rejected: Thread Starvation

High frequency REST polling introduced frame jitter during synchronous inspector scrolling passes.
