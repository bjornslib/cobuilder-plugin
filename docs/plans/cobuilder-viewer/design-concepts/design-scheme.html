04

Elevation & Surface Tint

Elevation in the CoBuilder specification repudiates traditional drop shadows. Visual depth is established exclusively via primary-derived surface color tinting.

info

System Architectural Rule

In CoBuilder's developer documentation viewer, elevation is communicated strictly through surface color tinting derived from the Primary role, eliminating drop shadows to maximize code readability and reduce visual fatigue.
